# Consumo de APIs Públicas com Python — IBGE e Banco Central

## Sobre o projeto

Este projeto foi desenvolvido como atividade prática de Python com o objetivo de trabalhar com **consumo de APIs públicas**, tratamento de dados e armazenamento de informações em diferentes formatos.

Foram utilizadas fontes oficiais de dados do:

* **IBGE — Instituto Brasileiro de Geografia e Estatística**
* **Banco Central do Brasil (BCB)**

O projeto utiliza a biblioteca `requests` para realizar requisições HTTP e `pandas` para transformar, tratar e analisar os dados.

---

## Objetivos

O projeto tem como principais objetivos:

1. Consumir dados de uma API pública do IBGE.
2. Consumir dados de um endpoint público do Banco Central.
3. Transformar os dados recebidos em `DataFrames`.
4. Exibir e analisar os dados obtidos.
5. Salvar os dados do Banco Central em formato CSV.
6. Realizar tratamentos e validações nos dados.
7. Salvar os dados tratados em CSV e Parquet.
8. Compreender as diferenças entre API e requisições sem API.
9. Compreender a importância e os riscos do web scraping.

---

# APIs utilizadas

## IBGE

Foi utilizada a API de localidades do IBGE:

`https://servicodados.ibge.gov.br/api/v1/localidades/municipios`

Essa API fornece informações sobre os municípios brasileiros.

No projeto são extraídas informações como:

* ID do município;
* nome do município;
* ID da microrregião;
* nome da microrregião;
* ID da mesorregião;
* nome da mesorregião.

Os dados recebidos em JSON são transformados em um `DataFrame` utilizando o Pandas.

---

## Banco Central do Brasil

Para o Banco Central foi utilizada uma série do **Sistema Gerenciador de Séries Temporais (SGS)**.

Endpoint:

`https://api.bcb.gov.br/dados/serie/bcdata.sgs.1/dados`

A série utilizada corresponde ao **dólar americano (venda)**.

O período consultado é de:

* Início: 01/01/2025
* Final: 31/12/2025

O resultado é recebido em formato JSON e convertido para um `DataFrame`.

> O exemplo utilizado no material de aula consulta dados de Transações Pix por Município. Para esta atividade foi utilizada uma fonte diferente, conforme solicitado no enunciado.

# Tratamento dos dados

Depois que os dados do Banco Central são carregados, são realizados alguns tratamentos.

## 1. Conversão da data

A coluna `data` é convertida para o formato de data do Pandas:

```python
df_bcb["data"] = pd.to_datetime(
    df_bcb["data"],
    dayfirst=True,
    errors="coerce"
)
```

Isso permite trabalhar corretamente com datas e realizar análises posteriores.

---

## 2. Conversão do valor

A coluna `valor` é convertida para um tipo numérico:

```python
df_bcb["valor"] = pd.to_numeric(
    df_bcb["valor"],
    errors="coerce"
)
```

Dessa forma, os valores podem ser utilizados em cálculos e análises estatísticas.

---

## 3. Remoção de valores ausentes

Registros que não possuem data ou valor são removidos:

```python
df_bcb = df_bcb.dropna(
    subset=["data", "valor"]
)
```

---

## 4. Remoção de duplicidades

Também são removidos registros duplicados:

```python
df_bcb = df_bcb.drop_duplicates()
```

---

## 5. Renomeação da coluna

A coluna `valor` recebe um nome mais descritivo:

```python
df_bcb = df_bcb.rename(
    columns={
        "valor": "dolar_venda_brl"
    }
)
```

Isso facilita a compreensão do significado da informação.

---

### Duplicidades

# API x requisição sem API

Uma **API (Application Programming Interface)** fornece uma interface estruturada para que programas possam acessar dados ou serviços.

Normalmente, APIs retornam dados em formatos estruturados, como:

* JSON;
* XML;
* outros formatos específicos.

Uma requisição **sem API** pode acessar diretamente uma página HTML, arquivo ou outro recurso disponível na internet.

Um exemplo é o download direto de um arquivo `.xls` do IBGE:

```text
Servidor do IBGE
       ↓
Arquivo XLS
       ↓
requests
       ↓
Arquivo no computador
```

Quando uma API oficial está disponível e fornece os dados necessários, geralmente ela é a opção mais adequada, pois oferece uma estrutura própria para integração entre sistemas.

# Web scraping

**Web scraping** é uma técnica utilizada para coletar automaticamente informações disponíveis em páginas da internet.

Pode ser útil no ambiente profissional para:

* pesquisa de informações;
* acompanhamento de preços;
* monitoramento de páginas;
* coleta de informações públicas;
* análise de dados;
* automatização de tarefas repetitivas.

Entretanto, o web scraping deve ser realizado de maneira responsável.

---

# Riscos legais e éticos

Alguns dos principais riscos são:

### Termos de uso

Um site pode estabelecer regras sobre como seus dados podem ser acessados e utilizados.

### Direitos autorais

Nem toda informação encontrada na internet pode ser livremente copiada ou redistribuída.

### LGPD

Quando existem dados pessoais envolvidos, é necessário observar a **Lei Geral de Proteção de Dados (LGPD)** e seus princípios.

### Sobrecarga do servidor

Uma quantidade excessiva de requisições pode prejudicar o funcionamento de um site.

---

#  Medidas para reduzir riscos

Duas medidas práticas são:

1. Verificar os termos de uso, regras de acesso e políticas do site antes de realizar a coleta.
2. Coletar somente os dados necessários, evitar dados pessoais desnecessários e controlar a quantidade de requisições realizadas.

Quando existir uma API oficial, também é recomendável dar preferência a ela em vez de realizar scraping diretamente das páginas.
